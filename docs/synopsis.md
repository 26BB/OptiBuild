## 2. Problem Statement
To design and implement **Opti Build**, an intelligent, resource-efficient multi-objective optimization system capable of dynamically handling user-defined constraints, providing Pareto-optimal configurations, and integrating real-time telemetry and user feedback via centralized issue management.

## 3. Motivation & Objectives
- **Objective 1:** Formulate a formal mathematical model for multi-constraint optimization.
- **Objective 2:** Conduct a comprehensive literature survey of state-of-the-art algorithms (2021–2026).
- **Objective 3:** Implement a lightweight, low-latency optimization heuristic.
- **Objective 4:** Deploy a live MVP and collect real-world user feedback using Jira as the central issue tracking hub.
- **Objective 5:** Publish a survey paper in Stage 1 and an empirical evaluation paper in Stage 2.
